# v5.0 维多利亚迁移审计、产品合同和术语层

本文是 v5.0 阶段记录。它把 `codex-v5.0-维多利亚时代aiagent历史策略迁移总提示词.md` 落成当前工程可执行的迁移合同、硬编码审计和后续版本边界。

本文件不代表维多利亚玩法已经实现。当前源码仍以 WWIIHexV0 二战阿登工程为代码基线；v5.0 只完成迁移审计、产品口径、术语表、风险清单和后续执行顺序。

## 1. 本轮目标

- 建立 `蒸汽帝国 Agent` / `Steam & Empire Agent Strategy` 的当前产品合同。
- 明确首发剧本为 `black_sea_crisis_1853` / `黑海危机 1853`。
- 扫描二战硬编码、二元阵营假设、旧 phase、旧资源、旧单位、旧 UI 文案和默认数据残留。
- 给 v5.1-v5.5 迁移划出执行顺序、文件边界和禁止项。

## 2. 本轮非目标

- 不改 Swift 业务逻辑。
- 不改 JSON 默认数据。
- 不改 Xcode project。
- 不做一次性大规模重命名。
- 不声称默认启动已经进入维多利亚剧本。
- 不跑 Xcode、XCTest、模拟器、Probe、Smoke、Stage Regression、Dynamic Theater Regression、Full 或性能测试。

## 3. 当前工程事实

当前主链路仍是：

```text
MapEditor / JSON 数据
  -> DataLoader
  -> GameState
  -> HexTile.controller + Division.coord
  -> Region 聚合
  -> EconomyState 收入 / 生产 / 补员
  -> DiplomacyState 草案
  -> Initial Theater snapshot + runtime hexToTheater
  -> FrontLine 动态 hex 接触
  -> WarDeployment hexToFrontZone + FRONT/DEPTH/GARRISON
  -> MarshalAgent / TheaterDirective JSON
  -> TheaterDirectiveDecoder / TheaterDirectiveCompiler
  -> ZoneDirective
  -> WarCommandExecutor
  -> RuleEngine
  -> StrategicStateSynchronizer
  -> UI / SpriteKit / 日志 / WarDirectiveRecord
```

必须保留的权威边界：

- `HexTile.controller` 和 `Division.coord` 是战术层权威。
- `RegionNode.controller` 是从 hex controller 聚合出来的战略快照。
- `regionToTheater` 是初始/基础战区归属，不是运行时推进权威。
- `hexToTheater` 是运行时动态战区权威。
- `hexToFrontZone` 是部署层动态归属权威。
- 玩家、AI、外交、经济和后续聊天命令都必须经 `Command` / `ZoneDirective` / `WarCommandExecutor` / `CommandValidator` / `RuleEngine` 或明确的新 validator/executor。
- Legacy Agent D 保留作回归参考，不作为默认战争 AI 主路径。

## 4. 产品合同

工作名：

- 中文：`蒸汽帝国 Agent`
- 英文：`Steam & Empire Agent Strategy`

时代范围：

- 约 1837-1901 年的维多利亚时代。
- 首版只做范围可控的危机剧本，不做完整全球七十年沙盒。

首发剧本：

```text
scenarioId: black_sea_crisis_1853
displayName: 黑海危机 1853
时间范围：1853-1856 克里米亚战争抽象战役窗口
地图范围：黑海、克里米亚、多瑙河口、巴尔干北缘、高加索西缘、君士坦丁堡方向
主要势力：Russia、Ottoman、Britain、France、Austria、Sardinia、Neutral
规模目标：120-220 个 hex，35-70 个 region，8-16 个军区/远征军防区
```

发布候选必须让玩家感知至少两个维多利亚机制：

- 铁路补给。
- 港口远征或海上补给。
- 外交危机。
- 战争目标。
- 工业预算。
- 战争支持或报纸舆论。
- 可审计的内阁 / 外交 / 战争 / 总参谋部 Agent 理由。

命名约定：

- 运行时 id 使用 ASCII，例如 `power_britain`、`region_sevastopol`、`theater_crimea_expedition`。
- 展示名、事件正文、报纸战报可以使用中文。
- 旧 `germany/allies`、`ardennes`、`panzer`、`bastogne` 可存在于旧数据、旧测试和历史文档，但不能作为发布默认主路径。
